# ☕ 기본 fetch() 단독 실습 (Live Server 전용)

`async/await`, `Promise.all`, `AbortController` 같은 고급 문법을 모두 제외하고,
자바스크립트 기본 통신 함수인 **`fetch()`**와 **`.then()` / `.catch()` 체이닝** 구조만 가장 단순하게 실습할 수 있도록 제작된 프로젝트입니다.

---

## 📁 파일 구성
* `index.html`: 결과 화면과 실시간 콘솔 창
* `script.js`: `fetch().then().catch()` 기본 로직
* `README.md`: 설명서

---

## 🚀 실행 방법 (Live Server)
1. 다운로드한 `weather-fetch-only-app.zip` 압축을 풉니다.
2. VS Code에서 **[파일] → [폴더 열기]**로 해당 폴더를 엽니다.
3. `index.html` 파일을 우클릭하고 **[Open with Live Server]**를 클릭합니다.
4. 브라우저에서 **[fetch()로 날씨 주문하기]** 버튼을 누르면 즉시 날씨가 출력됩니다.
